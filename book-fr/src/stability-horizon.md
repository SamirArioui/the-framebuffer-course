> **Horizon de stabilité — `lesson-001`…`lesson-103` sont figées ; la queue
> volatile est vide.** Le cours est complet — les six parties, de l'arc
> `wordcount` jusqu'au jeu terminé — et chaque état `lesson-NNN` est stable.
> Une étiquette figée ne bouge que pour un correctif de comportement, appliqué
> de façon chirurgicale avec les états en aval retaggués. Si une étiquette
> bouge sous vos pieds, restaurez votre arbre de travail à l'état de leçon
> courant avec `git checkout lesson-NNN -- sandbox/` (leçons 001-025, le code
> de la partie 0), `git checkout lesson-NNN -- src/` (leçons 026-043, le moteur
> avant les ressources), ou `git checkout lesson-NNN -- src/ assets/` (leçons
> 044-103, une fois les ressources présentes).
